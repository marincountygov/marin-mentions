    About

    Marin Mentions collects news stories, videos, and social media posts that mention Marin County, and shows them all in one place.

    How the list updates

    The list updates on its own about every 15 minutes. Reload the page any time to see the newest list.

    Saving mentions

    Check the box next to any mention to save it, or use Select all to save everything currently in the list. Once you check a box, a dropdown appears so you can pick which official County announcement that mention is about. If you've saved one or more mentions, the Copy button copies only those — otherwise it copies everything you're currently viewing. The dropdown next to Copy lets you choose how the copied text is organized: by news story, or grouped under each County announcement. The CSV button downloads the same list as a spreadsheet file. Saved mentions aren't kept after you close or reload the page.

    Charts

    Click the Stats button to see charts instead of the list — how many mentions came in over time, which outlets covered Marin County the most, and which topics came up most often. The charts match whatever you're currently filtering by. Each chart has its own PNG button to save it as an image; All PNG saves all three at once; Copy puts all three charts on your clipboard so you can paste them into an email or chat message.

    Things to know

    • The list only shows what was available the last time it updated. A story that was already gone from a site before we checked won't show up, even if it's from the right time period.
    • Some news links open through Google first instead of going straight to the article. That's normal, and the link still works.
    • YouTube and Reddit need special access set up to work, so they may not always be available. Bluesky doesn't need that, but can occasionally be slow or temporarily unavailable.

    Technical

    Marin Mentions is a stateless media-monitoring console for the San Francisco Bay Area, prioritizing Marin County. It combines direct publisher RSS, Google News RSS, YouTube, Bluesky, and Reddit into one feed, matched against keyword/phrase monitors defined in config/monitors.yaml.

    There is no database and no live per-request fetching. A scheduled GitHub Actions build runs roughly every ~15 minutes: it fetches every enabled source, matches monitors, deduplicates, merges the result with the previously published snapshot (keeping items from the last 7 days), and republishes data.json. Reloading the page re-fetches that same data.json — there's no separate manual-refresh action, and nothing on this page triggers a new build.

    Saved (clipped) mentions can be attributed to the County's own official releases — marincounty.gov news releases and the County's own YouTube channels — from the past 60 days, listed by title, newest first. Clips are session-only, held in memory, and reset on reload.

    Stats' Top Sources chart excludes the County's own official sources, so it reflects third-party coverage volume, not the County's own release/channel activity.

    • Time filters only apply to what the current snapshot holds. An item that scrolled off a source's own feed before it was ever fetched will never appear, even if it's within the selected time range.
    • Google News RSS links point to a Google redirect page, not the publisher's article directly — this is a Google limitation, not a broken link.
    • Deduplication prefers a direct publisher result over a Google News result for the same story, matched by outlet + headline since Google's redirect links can't be resolved to a canonical URL server-side.
    • YouTube requires an API key and Reddit requires OAuth credentials; see the README for activation status and quota/rate-limit notes. Bluesky's public search endpoint needs no key, but its reliability is outside this app's control.
