    About

    Marin Mentions is a stateless media-monitoring console for the San Francisco Bay Area, prioritizing Marin County. It combines direct publisher RSS, Google News RSS, YouTube, and Bluesky into one feed, matched against keyword/phrase monitors defined in config/monitors.yaml.

    How refresh works

    There is no database and no live per-request fetching. A scheduled GitHub Actions build runs roughly every 10–15 minutes: it fetches every enabled source, matches monitors, deduplicates, merges the result with the previously published snapshot (keeping items from the last 7 days), and republishes data.json. The Refresh button reloads that snapshot in your browser — it does not trigger a new fetch.

    Known limitations

    • Time filters only apply to what the current snapshot holds. An item that scrolled off a source's own feed before it was ever fetched will never appear, even if it's within the selected time range.
    • Google News RSS links point to a Google redirect page, not the publisher's article directly — this is a Google limitation, not a broken link. The link still works when clicked in a browser.
    • Deduplication prefers a direct publisher result over a Google News result for the same story, matched by outlet + headline since Google's redirect links can't be resolved to a canonical URL server-side.
    • YouTube and Bluesky require API access; see the README for activation status and quota/rate-limit notes.
